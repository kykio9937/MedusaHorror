# 主线流程与堡垒替换清单

## 当前主线

新游戏 → 无名医院中渐渐苏醒 → 搜索线索、掌握拾取与武器操作 → 二楼守望者 → 天台未知出口 → 虚拟网格解离、白光与人声提示的真实异步加载 → 荒原堡垒苏醒区 → 保安队队长说明真相 → 野外旧村庄巡防 → 回城报告与补给 → W0 专用训练场内 10 级解锁第三人称 → 20 级交通门 → W3 列车中转站 → 选择霓虹街区、异星之门或免费返回主城。

医院前期不出现“模拟、虚拟、守村训练、荒原考核”等设定文字。真实建筑科室牌、操作提示与眼前目标保留；未知成就暂时隐藏，装备页不提前推荐后续城市。首段苏醒以遮眼、眨眼和内心独白表现，结束后恢复操作并播放操作教程。

医院的线索、楼梯、二楼敌人与天台流程保留，但叙事改成寻找出口。真相在抵达堡垒后才由队长讲明：虚拟试炼为了让在城内长大的孩子掌握独立生存、应对怪物袭击和保护身边人的能力。这里的队长不是村长。

首次队长对话结束写入存档，再次回城不会强制重复。旧村野外原有任务 NPC 保留，原“村长”称谓改成“旧村联络员”。首次巡防需要实际走到旧村中央广场，不能只进场景就领奖；回城向队长报告后获得一次性 100 信用点与 120 经验。原有 NPC 委托增加可配置经验奖励（默认 80），后续经验曲线和达到 20 级的时间仍需实际试玩调平衡。

| 场景 | 职责 |
| --- | --- |
| W1_Hospital | 一次性序章与可重返的虚拟试炼；所有情况下固定第一人称 |

医院试炼只能从堡垒专用入口重返；主菜单新游戏与读档、当前关重开作为必要例外。20 级门禁同时在交互点和统一加载入口检查；旧场景不能直接跳过列车枢纽去后续关卡。

## 10 级视角训练（最终规则）

- 默认第一人称，W1 全程锁定第一人称，完成解锁后重返医院仍不允许第三人称。
- 剑支持第一人称和第三人称；默认第一人称有复用现有剑网格的持剑与挥砍表现，伤害仍由原近战系统判定。
- 第三人称权限需要达到 10 级，并进入 W0 训练场、在教官训练台前按 E、完成讲解；不能仅凭升级自动解锁。
- W2 保安队东侧 `GuardTrainingEntrance` 入口约 `(9, 0, -12)`，前往 W0；W0 `ThirdPersonTrainingConsole_ReplaceArt` 在约 `(0, 0.7, 6)`。
- 解锁后按 T 切换视角。剑可在两种视角使用；枪只能在第一人称使用，切枪会进入第一人称，持枪切到第三人称时先收枪换剑，保持原切换过渡和攻击锁定。
- 新存档字段是 `thirdPersonTrainingUnlocked`。老存档默认未解锁，需要到训练场完成一次训练，已有等级、装备与任务数据保留。
- W0 不再承担选关枢纽，不保留原多余传送门；训练场只保留返回 W2 的出口，另有三组不产出经验或信用点的可重复练习靶。

## 列车

上车前以鼠标或数字键选择目的地。霓虹街区、异星之门目前单次车费均为 200 信用点；返回堡垒免费。余额不足不扣费、不发车；重复选择不会重复扣票。发车后保留现有车厢旅程，到站使用真实异步场景加载。

## 主城美术占位与采购需求

当前堡垒是可玩框架，尚不是最终美术。没有找到可直接作为完整防御主城的现成素材包，所以没有把野外旧村庄冒充成主城，也没有代购或导入未知资源。

建议寻找：与现有荒原尺度和画风接近的模块化堡垒、末世聚居地或防御营地包，包含城墙、墙角、门楼、岗哨、道路、居住屋、队舍和补给设施。优先提供碰撞、LOD、可步行门洞和独立模块；避免只适合远景的整块建筑。

| 需要补充的素材 | 当前占位与替换位置 |
| --- | --- |
| 城墙、城门、哨塔、内城建筑 | W2_Stronghold 的 `Stronghold_ReplaceArtRoot`，子物件名含 ReplaceArt |
| 保安队队长 / 教官的合适角色 | 队长暂复用已有 Kazuko，`GuardCaptain_ReplaceModel`；教官暂以训练台对话表达 |
| 苏醒医疗仓、床、连接终端 | `RecoveryBed_ReplaceArt`、`RecoveryConsole_ReplaceArt` |
| 战术训练终端与标靶 | W0 `GuardTrainingRoot/ThirdPersonTrainingConsole_ReplaceArt` |
| 三种风格的主城入口 | `WildernessGate`、`TrialGate`、`TransitGate`，已有门框占位、灯光与交互 |
| 回归现实的精细音效、演出 | 现用已有心跳声和界面动画；可替换成苏醒舱声音、虚拟空间瓦解与环境渐入特效 |

替换外观时保留玩家、相机、队长交互、训练台、入口根物件及安全地面碰撞。第一人称剑复用现有剑网格与纹理，调整比例与镜头内挥砍，不改变伤害范围；第三人称继续使用角色原有持剑动画。

重新布置主城后要同步 `MapLocationResolver` 区域边界并重新烘焙导航。不要在已经制作好的主城重复执行删除式重建；当前装配工具只补缺失节点。
