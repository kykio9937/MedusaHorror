# Unity 2022 构建警告修复

## 素材包兼容修复

部分第三方素材目录没有纳入 Git。重新导入素材包后，在项目根目录运行：

```powershell
python tools/repair_legacy_warnings.py
```

脚本替换过时的导航、粒子、图像效果接口，修复重复成员、旧编辑器事件及 Windows 材质零除问题。可以重复运行；已修复时输出 `Changed 0 files`。Compass 字段改名保留旧序列化名称。

## 项目与场景

- 住宅的 HouseSavePoint、HouseStorage、FurnitureShop 分别使用同名脚本，W4 改为引用实际脚本资源，避免仅在编辑器有效的内嵌脚本；沙发购买点恢复家具模型引用。
- W3 使用单独的 W3_SubwayLighting.asset，关联实际地铁场景，保留原光照数据。
- 医院旧编辑器生成工具使用 NavMeshSurface 烘焙导航。
- 移除没有读取用途的字段、局部变量。
