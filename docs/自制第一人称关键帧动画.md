# 自制第一人称关键帧动画

本次复用现有 Kazuko 角色的手臂、手套和长剑，没有导入付费手臂或外部控制器。

## 动作资产

目录：`Assets/Resources/FirstPersonMotion/`。

| 片段 | 内容 |
| --- | --- |
| SwordIdle | 轻微呼吸起伏的双手持剑待机 |
| SwordWalk | 1.2 秒循环的慢节奏行走持剑 |
| SwordRun | 0.8 秒循环的低位跑步持剑 |
| SlashRight | 第一段：蓄力、横斩、随动、收招 |
| SlashLeft | 第二段：反向横斩 |
| SlashDown | 第三段：举剑、下劈、压腕收招 |
| SwordStow / SwordDraw | 收剑 / 拔剑 |
| GunHold | 持枪待机，保留已有右键瞄准与射击后坐力 |
| GunStow / GunDraw | 收枪 / 拔枪 |
| RecoverRight / RecoverLeft / RecoverDown | 第一段0.3秒、第二段0.7秒、第三段1.2秒收招后摇 |

所有片段均为原生 `.anim` 文件，包含 `RightGrip` / `LeftGrip` 的位置和旋转关键帧，60 fps 编辑采样率，曲线使用 ClampedAuto 切线。三个攻击片段以归一化一秒创作，运行时按各段 `comboDuration` 缩放播放。

## 控制与骨骼

`FirstPersonMotion` 通过 Animator 的 Playables 播放和融合片段。它只控制独立的握点层级，不与原来的全身 Animator 同时写同一批骨骼。`FirstPersonArms` 在动画采样后，用双骨解析 IK 旋转肩臂、肘和手腕，维持原始上臂/前臂长度，并允许小幅肩胛随动。

剑的朝向来自右握点，位置按掌心补偿挂在实际右手上；左手在剑柄下方配合握持。手指按实际指骨方向弯曲。双臂网格裁切后清除残留胸背骨骼权重，并重新归一化手臂权重，避免肩部重定位时蒙皮被原胸背骨骼拉成穿镜头的长条。

行走/跑步根据 CharacterController 实际移动速度选片段，顶墙没有移动时回到待机。切换武器继续使用原来的 1.6 秒流程：0.7 秒收起旧武器、0.9 秒拿出新武器，期间不能攻击。枪械保留第一人称限制，医院固定第一人称和训练解锁第三人称的规则保持原样。

近战伤害在原始完整动作 0.42 相位对应的出刀时刻判定，避免刚按下鼠标、剑还在蓄力时目标就先受伤。当前攻击片段已拆出独立后摇，因此代码按拆分比例换算命中时刻。暂停冻结动作时间，切换取消未完成的命中。

## 长按连击与后摇（2026-11-28更新）

按下左键立即出第一段。保持按住时，在当前攻击和该段完整后摇结束后追加下一段，最多三段；松开后当前动作完整结束，但不再追加。第三段后继续按住不会循环第四段，需要松开后再次按下才能开启新一轮。后摇内点击不会缓存到下一轮。

三段挥砍时长继续取各场景的 `comboDuration`，后摇分别为0.3/0.7/1.2秒，旧 `comboInterval` 仅保留用于序列化兼容。当前默认动作时长为0.34/0.36/0.52秒，因此持续按住时第二段约0.64秒开始，第三段约1.70秒开始，三段加最后收招共约3.42秒；实际边界按游戏帧推进。

三段后摇均有独立 `.anim`：从横斩、反斩、下劈的落点回到共同持剑待机。收招不产生额外伤害，不能通过再次调用攻击跳过后摇。输入层新增独立 `FireHeld`，枪械原有 `FirePressed` 逻辑保持。

最新长按连击验收：Unity运行86项通过、0错误、0警告，确认0.3/0.7/1.2秒资产时长、攻击与后摇关键帧连续、实际收招运动、一/二/三段松开行为、后摇攻击锁定、每段一次伤害，以及三段后不循环第四段。结果及前后姿势截图位于 `E:/UnityProjects/PlayerAnimationWork/HeldComboCheck/`；原存档与检查点逐文件恢复一致。

## 后续编辑

1. 把 `FirstPersonKeyframePreview.prefab` 临时拖入场景，选中它，打开 Window → Animation → Animation。
2. 从片段列表选择动作，展开 RightGrip / LeftGrip，编辑位置或旋转关键帧。这个预览预制体显示握点层级；实际蒙皮效果需在游戏播放中查看。
3. 保存 `.anim` 后，运行游戏检查手腕、剑柄和镜头边缘。不要改动 `RightGrip` / `LeftGrip` 节点名称。
4. `Medusa → 动画 → 生成自制第一人称关键帧` 会按制作脚本重新生成全部片段，覆盖手动调过的曲线；保留人工修改时不要重新生成。

编辑器工具 `FirstPersonAnimationAuthoring.cs` 保存了本次各动作的原始关键姿势，便于整体调整与重新生成。
