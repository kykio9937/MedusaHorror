# 小地图与实时定位

## 显示与操作

- 中继站、医院、荒原、地铁、霓虹区、异星关卡统一使用左上角小地图，主菜单隐藏。
- 地图下方左侧是场景名和当前房间/区域，右侧是楼层、朝向、X/Z 坐标和高度；每 0.1 秒更新。离开区域后恢复为公共通道或室外区域。
- 滚轮向上放大、向下缩小，有缩放上下限；打开背包、商店、对话或加载中不缩放。折叠状态不响应滚轮。
- 按 M 折叠/展开地图，折叠仍保留实时位置信息。
- 地图固定北向，玩家箭头实时旋转；只以每秒最多 8 次更新底图，箭头、图标正常跟随。
- 绿标：星门、返回符文、列车；红标：存活敌人；蓝标：商店；金标：未拾取的医院训练凭证。
- 远处导航目标沿方向贴边，超出地图的敌人/物品不堆积在边框。不同楼层的图标降低透明度；失效、死亡或离场的目标会隐藏/移除。
- 医院根据玩家高度切换一楼、二楼、天台底图，切入当前楼层内部避免顶层屋面遮挡；进入霓虹公寓切换室内俯视高度。
- 位置卡底板与配色随场景主题切换；任务追踪保留在右侧，与地图错开。

## 区域与扩展

区域名称基于玩家所在的三维范围，而不是全地图最近的物件。医院有各病房、任务房间、考核场、楼梯和天台范围；地铁有南北站台和西侧通廊；霓虹区有公寓内部，商店和星门的外围范围明确标为“附近”或接入区。

`MapLocationResolver` 缓存场景的区域与地标，`LevelMinimap` 更新地图和位置卡。以后移动医院房间或新增可进入的房间时，需要同步区域边界；已有商店、列车入口和星门按场景中的实际位置建立范围。不将无法进入的装饰建筑标成可探索房间。
